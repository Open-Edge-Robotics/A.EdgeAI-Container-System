# 사용자 관리 가이드

## 1. 사용자 역할 및 권한

### 1.1 관리자 (Administrator)
- 시스템 전체 설정 관리
- 모든 사용자 계정 관리
- 권한 설정 및 변경
- 시스템 로그 확인

### 1.2 일반 사용자 (User)
- 개인 정보 관리
- 기본 기능 사용
- 자신의 활동 내역 확인

## 2. 사용자 계정 관리

### 2.1 계정 생성
1. 관리자 페이지 접속
2. "사용자 추가" 버튼 클릭
3. 필수 정보 입력
   - 사용자 ID
   - 이메일
   - 비밀번호
   - 권한 레벨
4. "저장" 버튼 클릭

### 2.2 계정 수정
1. 사용자 목록에서 수정할 사용자 선택
2. "수정" 버튼 클릭
3. 변경할 정보 수정
4. "저장" 버튼 클릭

### 2.3 계정 삭제
1. 사용자 목록에서 삭제할 사용자 선택
2. "삭제" 버튼 클릭
3. 확인 메시지에서 "확인" 클릭

## 3. 비밀번호 관리

### 3.1 비밀번호 변경
1. "내 정보" 메뉴 접속
2. "비밀번호 변경" 선택
3. 현재 비밀번호 입력
4. 새 비밀번호 입력 (2회)
5. "변경" 버튼 클릭

### 3.2 비밀번호 정책
- 최소 8자 이상
- 대문자, 소문자, 숫자, 특수문자 포함
- 3개월마다 변경 권장

## 4. 보안 정책

### 4.1 로그인 정책
- 최대 로그인 시도 횟수: 5회
- 계정 잠금 시간: 30분
- 세션 타임아웃: 30분

### 4.2 접근 제한
- IP 기반 접근 제한 설정 가능
- 시간대별 접근 제한 설정 가능

## 5. 문제 해결

### 5.1 자주 발생하는 문제
1. 로그인 실패
   - 비밀번호 확인
   - 계정 잠금 여부 확인
   - 관리자에게 문의

2. 권한 오류
   - 현재 권한 확인
   - 필요한 권한 요청
   - 관리자에게 문의

### 5.2 지원 연락처
- 이메일: support@example.com
- 전화: 1234-5678
- 운영시간: 평일 09:00 - 18:00

## 1. 워크스페이스 개요

### 1.1 워크스페이스 정의
- 여러 프로젝트를 그룹화하여 관리하는 단위
- 사용자들이 협업할 수 있는 공유 공간
- 프로젝트 리소스와 설정을 중앙 집중식으로 관리

### 1.2 주요 기능
- 프로젝트 그룹화 및 관리
- 사용자 권한 관리
- 리소스 공유 및 협업
- 통합 모니터링 및 로깅

## 2. 워크스페이스 관리

### 2.1 워크스페이스 생성
1. "워크스페이스 생성" 버튼 클릭
2. 기본 정보 입력
   - 워크스페이스 이름
   - 설명
   - 접근 권한 설정
3. 초기 설정 구성
   - 기본 프로젝트 템플릿 선택
   - 사용자 초대
4. "생성" 버튼 클릭

### 2.2 워크스페이스 수정
1. 워크스페이스 설정 메뉴 접속
2. 수정할 정보 선택
   - 기본 정보 수정
   - 권한 설정 변경
   - 리소스 할당 조정
3. "저장" 버튼 클릭

### 2.3 워크스페이스 삭제
1. 워크스페이스 설정 메뉴 접속
2. "워크스페이스 삭제" 선택
3. 삭제 확인
4. "삭제" 버튼 클릭

## 3. 사용자 권한 관리

### 3.1 워크스페이스 소유자
- 워크스페이스 생성 및 삭제
- 사용자 초대 및 제거
- 권한 설정 및 변경
- 리소스 할당 관리
- 전체 설정 관리

### 3.2 워크스페이스 관리자
- 사용자 관리
- 프로젝트 관리
- 리소스 모니터링
- 설정 변경

### 3.3 일반 사용자
- 프로젝트 접근 및 작업
- 리소스 사용
- 협업 기능 사용

## 4. 프로젝트 관리

### 4.1 프로젝트 생성
1. 워크스페이스 내 "프로젝트 생성" 선택
2. 프로젝트 정보 입력
   - 프로젝트 이름
   - 설명
   - 클러스터들

3. 템플릿 선택
4. "생성" 버튼 클릭

### 4.2 프로젝트 설정
- 클러스터터 할당
