### Test

아래의 명령어를 이용하여, Runner가 연결되는지 확인한다.

```sh

docker run --rm -v /srv/gitlab-runner/config:/etc/gitlab-runner gitlab/gitlab-runner register \
  --non-interactive \
  --url "https://git.etri.dev" \
  --token "glrt-t3_iKWmiadj5c1ucYQ5QDs1" \
  --executor "docker" \
  --docker-image alpine:latest \
  --description "docker-runner"

```

### install runner

```sh
helm install --namespace gedge webserver-gitlab-runner -f yaml/runner-values.yaml gitlab/gitlab-runner
```


### uninstall runner

```sh
helm install --namespace gedge webserver-gitlab-runner
```
